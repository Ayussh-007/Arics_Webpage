# 🔐 SECRET ADMIN ACCESS - Quick Guide

## How to Access Admin Panel

### Desktop:
1. Go to customisation page (`/customize`)
2. **Hold Shift key**
3. **Click on "Custom Bouquet Builder" title 3 times quickly** (within 2 seconds)
4. Admin panel appears!

### Mobile:
Same as desktop - Hold Shift (if using external keyboard) + Tap title 3 times

---

## Why This Method?

✅ **Secure** - Not visible to regular customers
✅ **Simple** - Easy for admin to remember
✅ **Fast** - Quick access when needed
✅ **Hidden** - No UI hints for unauthorized users

## Admin Features Available:

1. **Orders** - View all customer orders
2. **Flowers** - Add, edit, enable/disable flowers
3. **Customizations** - Manage wrapping, ribbons, addons
   - Add new categories
   - Add multiple options to each category
   - Edit prices and labels
   - Remove individual options
4. **Settings** - Configure tax, delivery, fees

## Troubleshooting:

**Not working?**
- Hold Shift BEFORE clicking
- All 3 clicks within 2 seconds
- Click on the title text, not elsewhere
- Refresh page and try again

**Forgot credentials?**
- Check `server/.env` file
- Default email: `admin@arics.com`
- Reset password in database if needed
